# Fieldnotes

A free static student guide to practical future skills. The site includes four guided paths (AI literacy, data, cybersecurity, web development), a path picker, searchable filters, local progress checklists and progress export.

## Privacy and security

The site has no server, user accounts, forms, uploads, tracking scripts, external fonts, or third-party JavaScript. Checklist progress stays in the visitor's browser. A Content Security Policy limits scripts and styles to the site's own files. Course links open separately with `noopener noreferrer`.

## Search

This release includes page metadata, canonical URL, Open Graph metadata, WebSite structured data, `robots.txt`, and an XML sitemap. After it is live, add its URL to Google Search Console and submit `/fieldnotes/sitemap.xml` to request discovery. Search inclusion and ranking are determined by search engines and cannot be guaranteed.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive layout and visual design
- `app.js` — learning paths, quiz, and on-device progress
- `robots.txt`, `sitemap.xml` — crawler discovery files

## Analytics

No analytics provider is connected in this release. Static GitHub Pages does not provide a private, website-level visitor dashboard by itself. Add a privacy-conscious analytics property after choosing the provider; do not put private access tokens in these public files.
